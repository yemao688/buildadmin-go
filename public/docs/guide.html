文档模块引导

框架内置 /docs 静态文档服务（public/docs/）的使用引导。本文档本身即用法示例，业务仓库可整体替换或删除。

用法说明 目录约定 配置与密码门 常见问题

用法说明

框架已内置可选的 /docs 静态文档服务：把图文操作指南（*.html、图片等）放进 public/docs/ 目录，即可通过 /docs/ 访问，不需要改动任何后端装配代码。

启用方式

在 configs/config.yaml 中开启（默认关闭，不挂载）：

app:
  docs_enabled: true      # 挂载 /docs 静态服务
  docs_password: ''       # 留空公开；非空时开启服务端密码门

保存后重启后端（air 或重新 go run ./cmd/server），打开 http://localhost:9900/docs/。目录请求不展示文件列表（返回 404），请直接访问具体文档 URL，或提供 index.html 作为入口页。

目录约定

发布文档时请遵循以下约定：

  1. public/docs/ 根目录只放 HTML 文件，一份文档一个文件（如 guide.html、install.html）。
  2. 图片按文档分目录：每份 HTML 的图片统一放进对应的 public/docs/images/<文档名>/（如 guide.html 对应 images/guide/）。
  3. 页面内用相对路径（如 images/guide/step-flow.svg）或绝对路径（如 /docs/images/guide/step-flow.svg）引用图片。
  4. 图片与 HTML 同属 public/docs/ 发布，提交到仓库后随项目部署，无需走上传模块。
  5. /docs/ 及任何目录请求都不展示文件列表（返回 404），访问请用具体文档 URL（如 /docs/guide.html）；如需根路径入口，可自行提供 index.html。

当前目录结构示例：

public/docs/
├── guide.html              # 根目录只放 HTML
└── images/
    └── guide/              # guide.html 的图片
        └── step-flow.svg

配置与密码门

配置说明
app.docs_enabled是否挂载 /docs，默认 false（不挂载，行为同历史版本）。
app.docs_password访问密码，留空公开访问；非空时挂载服务端密码门。
DOCS_PASSWORD 环境变量覆盖 YAML 密码，机密走环境，避免写入仓库或镜像；仅在 docs_enabled 开启时生效。

密码门行为

  • 未携带有效 cookie 访问 /docs/*：返回密码页（POST /docs/password 验密）。
  • 验密通过：写入 ba_docs_auth cookie（HttpOnly，7 天）并回跳原路径。
  • 密码门只防随意浏览（共享密码），不是安全边界；敏感内容请走既有登录体系。

常见问题

问题说明
访问 /docs 返回 404？未开启 app.docs_enabled（默认关闭）、目录为空，或请求的是目录路径（目录不展示列表，请访问具体文档 URL，如 /docs/guide.html）。
密码门如何退出？清除浏览器中 ba_docs_auth cookie（或换无痕窗口），7 天后自动过期。
如何让 /docs/ 有入口页？在 public/docs/ 提供 index.html，/docs/ 会直接渲染它。
